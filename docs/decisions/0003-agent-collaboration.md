# ADR 0003: Three-Agent Parallel Engineering Model

## Context
Accelerating development without code collisions requires clear boundaries between frontend, backend, and platform/contracts.

## Decision
We established a strict three-agent division of labor:
- Agent 1: Frontend & UI
- Agent 2: Backend & Database
- Agent 3: Architecture, Shared Contracts & CI

## Status
Accepted and verified in Phase 0.
